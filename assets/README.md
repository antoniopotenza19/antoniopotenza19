# Portrait

`antonio-cartoon.png` was generated with the built-in Imagegen tool from Antonio's supplied photograph. It retains a transparent background. The original photograph is not included in this public repository.

Final generation prompt:

> Use case: style-transfer, identity-preserve. Edit target: the attached photographic portrait of Antonio. Transform this exact photograph into a polished hand-drawn 2D cartoon portrait for his GitHub profile README. Preserve his recognizable facial identity, face shape, thick wavy brown hair, hazel eyes, black rounded rectangular glasses, light stubble, slight head tilt, calm expression, navy suit, white shirt and navy tie. Same frontal head-and-shoulders composition, entire hair visible with a little breathing room above and shoulders flowing naturally to bottom edge. Crisp expressive ink contours, elegant cel shading, restrained warm skin colors and dark navy clothing, tasteful editorial cartoon rather than photoreal or 3D. Simplify texture and use clearly separated tonal shapes so the portrait also converts well to monochrome ASCII. Isolated subject on actual transparent background. No scenery, no computers, no props, no text, no border, no logos. Square composition. Do not add a smile, change hairstyle, remove glasses, or change clothing.

`data/portrait-ascii.txt` is produced by `scripts/prepare_card_assets.py` and used by the header card. It isolates the face and hair; the color portrait remains available separately.
