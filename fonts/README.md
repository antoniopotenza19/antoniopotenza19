These WOFF subsets embed Instrument Serif, Geist and Geist Mono into the profile SVGs.
Sources: [Google Fonts](https://github.com/google/fonts) (`ofl/instrumentserif`, `ofl/geist`, `ofl/geistmono`).
The corresponding SIL Open Font License files are included here.
Run `python scripts/prepare_card_assets.py` to download the original fonts and regenerate the subsets.
